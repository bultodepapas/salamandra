# Low-speed trim redesign outputs

These files are generated by
[`low_speed_trim_redesign.py`](../low_speed_trim_redesign.py). They are design
evidence, not measured polars and not manufacturing authority.

| Prefix | Configuration | Coverage | Disposition |
|---|---|---|---|
| `r1-sm8` | Released r1 geometry, +3 deg wash-in, 8% nominal static margin | Quick 45/95/105 km/h comparison | Fails at least one CG-band corner within the mechanical limit |
| `r2a-sm5` | Test candidate: 3.0/2.5 deg root/tip reflex, +3 deg wash-in, 5% nominal static margin | 45/60/75/95/105 km/h, root/mid/tip, Ncrit 6/10 | All 30 cases screen inside 11.04 deg, but 22 use control-deflection extrapolation and remain unvalidated |

The `*-xfoil-matrix.csv` files contain the converged XFOIL section rows. The
`*-trim-results.csv` files contain the VLM/section-polar coupling for aft,
nominal and forward CG. Metadata records the exact solver identity and binary
hash. The hidden `.xfoil-cache/` is reproducible working data and is ignored by
Git.

The measured-data path can set `measured_trim_subgate_pass=true`. The solver
always retains `physical_gate_closed=false`: uncertainty, `CLmax`/stall order,
hinge hysteresis and O1 drag propagation require separate signed dispositions
in the E2A test record. XFOIL cannot pass either gate.
